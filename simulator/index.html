Try the analyzer without the hardware

The screen below runs the device firmware's display, touch, and calibration code, ported to the browser. A simulated galvanic sensor feeds it, so readings settle the way a real cell does.

Tap the screen to switch pages · Hold 1.5 s to calibrate to air

Gas at the sensor20.9 % O₂

Sensor output in air10.5 mV

A healthy cell reads 8–14 mV in air. Below 7 mV the firmware flags it as weak. Set it to 0 to unplug the sensor.

Battery3.95 V

Hardware

The firmware only looks for the ADC at boot, so power-cycle after changing it. Calibration survives a power cycle, as it does in the device's flash.

Things to try

    
    
      
  1. On first boot the status line says HOLD: CAL AIR. With the gas set to Air, hold the screen until it shows CAL 20.9% OK.
    2. 
      
  2. Switch the gas to EAN32. The ring turns orange and the status reads SETTLING while the cell responds, then STABLE once readings hold within 0.15 % for 2 s. The MOD line shows depths at PO₂ 1.4 and 1.6.
    3. 
      
  3. Tap the screen for the detail page: raw millivolts, calibration values, and battery voltage.
    4. 
      
  4. Drop the sensor output below 7 mV and recalibrate to see the weak-sensor warning. Untick the ADS1115 and power-cycle to see NO ADC.
    5. 
      
  5. For a two-point calibration, calibrate in air, switch to O₂, wait for it to settle, then send o from the serial monitor.
